# Café Ashiana

Website proposal for Café Ashiana, a shisha lounge and halal restaurant on Curzon Street, Derby.

**Live:** https://ashiana-cafe.grabafaceit.workers.dev

## What's inside

- Dark, warm design built around their logo and their neon sign "There's no place like home"
- Live open or closed status by London time, including late nights after midnight
- Full menu with a category index and search (on mobile, one category at a time)
- Shisha flavour list, lounge gallery, digital loyalty card, FAQ, opening hours and directions
- Mobile bar with Call, Directions, Menu and Order

## Tech

Plain HTML, CSS and JavaScript, no framework and no build step. All data is in `data/site.js` and `data/menu.js`. Lighthouse: 100 on desktop, 97 on mobile.

## Run locally

```
node serve.mjs
```

Then open http://localhost:8080.
